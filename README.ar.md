يعمل «صدى ستوديو» على حاسوب المسجد، بجوار الكاميرا والميكروفون. تقرنه مرّة واحدة بنسختك من «صدى»، ثم
ينتظر: وحين يبدأ الجدول (أو أحد المستخدمين من لوحة الإدارة) بثًّا مباشرًا، يبثّ إلى «صدى» الذي يرسله بدوره
إلى فيسبوك أو يوتيوب أو أي وجهة RTMP، ويسجّله ويُعدّ التفريغ النصّي والمقاطع القصيرة. وعند انتهاء البثّ
يعود إلى وضع الانتظار.

يغني عن OBS في المساجد التي تستخدم النسخة المستضافة من «صدى»: لا إعداد ولا تشغيل يدوي.

## المزايا

- **الاقتران برمز**: أدخل عنوان نسختك من «صدى»، ثم اكتب الرمز الظاهر في لوحة الإدارة. هذا كل الإعداد.
- **دون تدخّل**: يبدأ مع الحاسوب، ولا يبثّ إلا حين يأمر «صدى» ببثّ مباشر، ويجهّز الكاميرا قبل الموعد
  المجدول بوقت قصير.
- **بثّ يدوي**: ابدأ خطبة أو درسًا أو محاضرة خارج الجدول، بعنوان تختاره. ولا يقطع موعد مجدول بثًّا يدويًّا.
- **بثّ واحد لكل مسجد**: إن كان OBS أو جهاز آخر يبثّ بالفعل، يُرفض «ستوديو»؛ ويمكن للمدير أن يتولّى
  البثّ من لوحة الإدارة.
- **سلامة الحاسوب**: الكاميرا، والميكروفون، والسكون، وتسجيل الدخول التلقائي، وساعات تحديث Windows.
  تأتي كل مشكلة مع حلّها، ويرسل «صدى» بريدًا إلى المسجد إن بقي عطل دون إصلاح.
- **متين**: نسخة واحدة قيد التشغيل، وأيقونة في شريط المهام، واستعادة بعد الأعطال، وإعادة اتصال تلقائية
  عند عودة الشبكة أو الكاميرا.
- **تحديثات تلقائية**، لا تحدث أثناء البثّ ولا قبل موعد مجدول مباشرةً.

## التنزيل

مثبّتات Windows وmacOS وLinux في صفحة [الإصدارات](https://github.com/sadakhutbah/sada-studio/releases).
يحتاج «ستوديو» إلى نسخة من «صدى» يقترن بها: مستضافة ذاتيًّا ([sada](https://github.com/sadakhutbah/sada))
أو النسخة المستضافة.

## التطوير

يتطلّب Node.js 22.

</div>

```bash
npm ci
npm run mock                                          # mock Sadā server on http://127.0.0.1:8787
SADA_STUDIO_INSTANCE=http://127.0.0.1:8787 npm run dev  # app with hot reload, paired to the mock
npm run lint && npm run typecheck && npm test
```

<div dir="rtl">

دون كاميرا (WSL أو التكامل المستمر)، اضبط `SADA_STUDIO_FAKE_MEDIA=1`.

البنية: `src/core/` (الاقتران، وآلة حالات الكشك، وفحوص السلامة، وعميل الواجهة البرمجية)، و`src/main/`
(النافذة، وأيقونة الشريط، وتخزين الأجهزة، والمحدّث)، و`src/renderer/` (واجهة React)، و`scripts/` (الخادم
التجريبي، والأيقونات)، و`tests/`. عقد الخادم موثّق في
[`docs/studio-devices.md`](https://github.com/sadakhutbah/sada/blob/main/docs/studio-devices.md)
في مستودع «صدى».

بناء المثبّتات ونشر التحديثات: [`docs/releasing.md`](docs/releasing.md).
